# Freelance Tutoring Service Website

This project is part of IS229 Assessment 2.  
It demonstrates a multi‑page website built with semantic HTML5 and basic CSS, published via GitHub Pages.

## Sitemap
- **Home (index.html)** – Welcome message and overview
- **About (about.html)** – Mission and background
- **Services (services.html)** – Subjects offered + pricing table
- **Gallery (gallery.html)** – Photos and events
- **Contact (contact.html)** – Inquiry and booking form

## Technologies Used
- HTML5 (semantic structure)
- CSS (basic styling for readability and spacing)
- Git + GitHub (version control and repository hosting)
- GitHub Pages (site publication)
